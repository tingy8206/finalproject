# finalproject
夜間智慧照護的系統流程與狀態設計：
1.	系統狀態定義
　　本系統設計兩個主要狀態：
  1.	在床狀態（inbed）
    •	壓力感測器偵測到壓力
    •	系統待命，不進行距離偵測
  2.	離床狀態（offbed）
    •	壓力感測為0
    •	啟動距離偵測與跌倒判斷流程

2.	事件流程說明
  a.	正常離床流程：
    	壓力感測值變為0
    	系統由inbed轉換為offbed
    	LED_str亮起，表示開始進行離床監測
    	紀錄離床開始時間
    	量測床邊距離作為跌倒基準值
  b.	跌倒事件判斷流程：
    	系統（超音波）持續量測離床距離
    	對資料進行：
      i.	多次平均（distance averaging）
      ii.	滑動視窗平滑處理（moving average）
　  　若符合以下條件，判定為疑似跌倒：
    •	距離平均值大於基準距離+12cm
    •	此狀態連續出現 5 次以上
　  　符合條件後：
    •	 LED_F燈亮
    •	記錄跌倒發生時間
  c.	回床與事件結束
    	壓力感測器再次感受到壓力，壓力值變為1
    	系統判定患者回床
    	結束當次紀錄
    	輸出：
      i.	離床開始時間（年/月/日 時:分）
      ii.	事件編號
      iii.	持續時間
      iv.	是否發生跌倒
      v.	跌倒發生時間（若有）
